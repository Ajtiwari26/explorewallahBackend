# ExploreWallah Backend API Server

Backend microservice for Explore Wallah Platform & Admin Portal built with Node.js, Express, TypeScript, and MongoDB Atlas.

## Features
- Express REST APIs for Treks, Packages, Users, Bookings & Admin
- JWT Authentication & BCrypt Password Hashing
- MongoDB Atlas database integration (Mongoose)
- Google Gemini AI RAG capabilities
- PDF Invoice generation
- Real-time WebSockets
